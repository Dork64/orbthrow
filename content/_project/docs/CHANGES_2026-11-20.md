# Orbthrow — изменения 20.11.2026

## Готово

- 34 сферы, дублировавшие Scepter/Shard или зависевшие от выдаваемой ими способности, заменены новыми. Размеры пулов сохранены: 309 синих, 326 фиолетовых, 108 легендарных, плюс 13 серых. У каждого героя по-прежнему 8 обычных фиолетовых, 4 механики и 4 легендарки.
- Ещё у двух сохранённых легендарок заменено пробуждение-дубль: Rupture Сикера теперь получает дополнительно +15 процентных пунктов урона от движения; Lunar Orbit Луны — +40 скорости вращения.
- Добавлена проверка генератора: прямые повторы ключей Scepter/Shard и сферы на выдаваемые ими способности останавливают сборку. Ручная проверка механик остаётся необходимой.
- Дополнительные заряды перенесены на AbilityCharges/AbilityChargeRestoreTime и штатный счётчик. Собственные параллельные таймеры и сброс КД после каждого применения удалены. Получение сферы и пробуждение добавляют только новые заряды, повторные тики их не заполняют. Последовательную очередь восстановления ведёт Дота.
- Серые сферы дают по 5% сопротивления эффектам, до 50%. Серые, Неудержимость и геройские баффы сфер (включая Железную волю Акса) объединены с общим потолком 50%; предметы и обычные способности Доты складываются отдельно по правилам игры.
- BKB: базовый КД 95 → 80 с. Цена, длительность и магическое сопротивление не усилены; серые сферы КД предметы не сокращают.
- Индикаторы: независимое восстановление циклов после исключения, проверка валидности панелей, уникальные имена при пересоздании, согласованные экранные координаты. В сетевой подписи сундука учтена высота.
- Бинды: по умолчанию 5/6/7/8 — обсервер/сентри/дым/пыль. ПКМ по слоту меняет раскладку. Привязана только выбранная раскладка; цифры других раскладок не захватываются заранее. Применение направляется герою даже при выбранном курьере/иллюзии. Устаревшая клиентская таблица больше не блокирует запрос. При отсутствующей способности есть две ограниченные попытки после запроса восстановления серверу.
- Сборка адаптирована для Windows: локально создаются папки build/game и build/content без Linux-команд архивации; резервные копии исключены из снимка.

## Баланс новых сфер

Обычные синие улучшают отдельные значения, с прежним уменьшением прибавок после порога. Уменьшаемые значения не опускаются ниже четверти исходных. Новые сильные удары работают только по героям, имеют отдельный счётчик атак по цели и ограничение частоты. Это не подтверждение идеального баланса: живые партии ещё не проводились.
